신청 자리: 네이버 개발자센터 → **Application → 내 애플리케이션 → shhh! → 개발 상태 → 검수요청**

---

## ⛔ 먼저 고칠 것 — 서비스 URL

지금 등록된 `https://bu202.github.io` 는 **404 다.** 앱은 `/shhh-app/` 아래에 있어서, 검수자가
서비스 URL 을 열면 GitHub 의 404 페이지를 본다. 이 상태로 신청하면 거의 확실히 반려된다.

| 자리 | 지금 | 바꿀 값 |
|---|---|---|
| 서비스 URL | `https://bu202.github.io` ← **404** | `https://bu202.github.io/shhh-app/` |
| Callback URL | `https://bu202.github.io/shhh-app/` | 그대로 |

바꿔도 「서비스 URL 도메인 = Callback URL 도메인」 조건은 그대로 지켜진다(오히려 경로까지 같아진다).

## 검수 요청 때 적을 말 (그대로 복사해 쓸 수 있음)

> shhh! 는 한국어를 한국수어(KSL)로 바꿔 보여주는 학습 웹앱입니다. 국립국어원 한국수어사전 데이터를
> 사용해 단어의 손모양과 수형 설명을 보여주고, 사용자가 외우고 싶은 단어를 '우리 단어장'에 담아
> 연습 문제로 복습합니다.
>
> 네이버 로그인은 **단어장을 기기 밖에 저장해 사용자가 기기를 바꿔도 이어서 쓰게 하는 용도로만**
> 사용합니다. 받는 정보는 **네이버가 주는 회원 고유번호(id) 하나뿐**이며, 이름·이메일·별명·프로필
> 사진·성별은 요청하지도, 저장하지도 않습니다. 별명은 앱 안에서 사용자가 직접 입력하는 값이고
> 네이버에서 가져오지 않습니다.
>
> 저장 위치는 Cloudflare Workers KV 이고, 저장하는 것은 (회원 고유번호, 단어장 단어 목록,
> 사용자가 입력한 별명, 로그인 세션 토큰)뿐입니다. 앱의 '마이 → 설정 → 계정과 단어장 삭제'에서
> 사용자가 직접 전부 지울 수 있습니다.
>
> 회원가입 절차는 따로 없고, 소셜 로그인 자체가 가입입니다. 로그인 없이도 사전 검색과 연습 기능을
> 그대로 쓸 수 있습니다.

## 첨부할 스크린샷 (거절 사유 1순위가 "스크린샷 누락"이다)

라이브에서 직접 찍는다: <https://bu202.github.io/shhh-app/>

1. **로그인 화면** — 앱을 처음 열면 나오는 게이트(카카오/네이버/구글 버튼 + "로그인 없이 둘러보기")
2. **로그인 진행** — 네이버 동의 화면
3. **로그인 후 화면** — 마이 탭(현재 플랜 + 계정)
4. **설정 화면** — 마이 → ⚙ (계정 / 결제 및 구독 / 개인정보처리방침 / **계정과 단어장 삭제** / 로그아웃)
5. **개인정보처리방침** — `privacy.html` 의 "로그인했을 때 저장되는 것" 부분

4번과 5번을 꼭 넣는다. "받는 정보가 고유번호뿐"이라는 주장과 "사용자가 직접 지울 수 있다"는 주장을
화면으로 뒷받침하는 자리다.

## 알아둘 것

- 거절 사유로 가장 흔한 것은 ① 안 쓰는 개인정보를 동의항목에 켜 둠 ② 스크린샷 누락이다.
  우리는 ①에 해당할 게 없다 — 동의항목이 0개다. 그러니 ②만 챙기면 된다.

  흰 글씨 "네이버로 로그인" 이라 취지에는 맞지만, 공식 버튼 이미지를 쓰라는 요구가 오면 그때 교체한다.
