## ⛔ 먼저 고칠 것 — 서비스 URL

아래 표는 **GitHub Pages 시절의 기록**이다. 현재 배포는 Cloudflare Pages(`shhh-app.pages.dev`)이므로
등록 값을 그 주소로 바꿔야 하고, 커스텀 도메인을 붙이기로 하면 그때 다시 바꾼다.

|---|---|---|
| 서비스 URL | `https://bu202.github.io` ← **404** | `https://shhh-app.pages.dev/` |
| Callback URL | `https://bu202.github.io/shhh-app/` | `https://shhh-app.pages.dev/` |

## 검수 요청 때 적을 말 (그대로 복사해 쓸 수 있음)

> shhh! 는 한국어를 한국수어(KSL)로 바꿔 보여주는 학습 웹앱입니다. 국립국어원 한국수어사전 데이터를
> 사용해 단어의 손모양과 수형 설명을 보여주고, 사용자가 외우고 싶은 단어를 '우리 단어장'에 담아
> 연습 문제로 복습합니다.
>
> 네이버 로그인은 **단어장을 기기 밖에 저장해 사용자가 기기를 바꿔도 이어서 쓰게 하는 용도로만**
> 사용합니다. 받는 정보는 **네이버가 주는 회원 고유번호(id) 하나뿐**이며, 이름·이메일·별명·프로필
> 사진·성별은 요청하지도, 저장하지도 않습니다. 별명은 앱 안에서 사용자가 직접 입력하는 값이고
> 네이버에서 가져오지 않습니다.
>
> 저장 위치는 Cloudflare D1 이고, 저장하는 것은 (회원 고유번호, 저희가 따로 만든 무작위 계정 번호,
> 단어장 단어 목록, 사용자가 입력한 별명, 로그인 세션 토큰의 해시, 친구 관계, 초대 코드)뿐입니다.
> 회원 고유번호는 계정 행 안에만 두고 밖으로 나가지 않으며, 나머지는 전부 무작위 번호로 저장합니다.
> 앱의 '마이 → ⚙ 설정 → 계정 → 계정 삭제'에서 사용자가 직접 전부 지울 수 있습니다
> (단어장만 비우려면 '우리 단어장' 화면의 '단어장 비우기').
>
> **현재 구현에는 별도의 회원가입 절차가 없고, 소셜 로그인 성공 자체가 계정 생성입니다.**
> 로그인 없이도 사전 검색과 연습 기능을 그대로 쓸 수 있습니다.

> ⚠️ 위 문단의 「회원가입 절차가 없다」는 **2026-08-17 현재 사실**이다. 3단계에서 명시적 가입 화면을
> 만들면 이 문장을 그때 고친다 — 미리 고쳐 두면 없는 기능을 있다고 제출하게 된다.

## 첨부할 스크린샷 (거절 사유 1순위가 "스크린샷 누락"이다)

라이브에서 직접 찍는다: <https://shhh-app.pages.dev/>
⚠️ **OAuth 가 비활성인 동안에는 2·3·4번을 찍을 수 없다**(로그인이 완료되지 않는다).

1. **로그인 화면** — 앱을 처음 열면 나오는 게이트(카카오/네이버/구글 버튼 + "로그인 없이 둘러보기")
2. **로그인 진행** — 네이버 동의 화면
3. **로그인 후 화면** — 마이 탭(현재 플랜 + 계정)
4. **계정 화면** — 마이 → ⚙ 설정 → 계정 (**계정 삭제** 버튼이 보이게)
5. **개인정보처리방침** — `privacy.html` 의 "로그인했을 때 저장되는 것" 부분

4번과 5번을 꼭 넣는다. "받는 정보가 고유번호뿐"이라는 주장과 "사용자가 직접 지울 수 있다"는 주장을
화면으로 뒷받침하는 자리다.
