## 1. 콘솔에 등록할 값

| 자리 | 값 | 코드 근거 |
|---|---|---|
| 서비스 URL | `https://shhh-app.pages.dev` | 배포 대상 |
| Callback URL | `https://shhh-app.pages.dev/` ← **앱 주소 그대로** | `worker/index.js` `redirectUri()` · `P.naver.viaApp = true` |
| 개인정보처리방침 | `https://shhh-app.pages.dev/privacy.html` | 저장소의 `privacy.html` |
| 이용약관 | `https://shhh-app.pages.dev/policies/` | `policies/index.html` |
| 로고 | `brand/logo-200.png` (200×200) · 큰 규격은 `brand/logo-512.png` | — |
| 제공 정보(동의항목) | **0개** — 회원 고유번호(`id`)만 사용 | `P.naver.scope = ""` · `uid: (j) => j.response.id` |

> ⛔ **옛 기록 — 2026-08-17 이전.** 이 문서는 `https://bu202.github.io` (GitHub Pages)를 서비스
> URL 로 적고 있었다. 그 주소는 404 다. 콘솔에 그 값이 남아 있으면 **바꿔야 한다.**

### 네이버만 콜백이 다른 이유 (검수자 질문이 나올 수 있는 자리)

네이버는 서비스 URL 을 하나만 받으면서 Callback URL 이 그 도메인 안에 있기를 요구한다.
그래서 **네이버만** code 가 앱 주소(`/`)로 돌아오고, 앱이 그 code 를 `POST /api/exchange/naver`
로 서버에 넘겨 교환한다. 카카오·구글은 서버 주소(`/api/cb/<제공자>`)로 직접 받는다.
토큰 교환과 사용자 판별 코드는 세 제공자가 **같은 함수**를 쓴다(`verifyProvider()`).

## 2. 검수 요청서에 적을 말 (그대로 복사해 쓸 수 있음)

> shhh! 는 한국어 낱말에 대응하는 **한국수어(KSL) 단어**를 찾아 보여주는 학습 웹앱입니다.
> 국립국어원 한국수어사전 데이터를 사용해 단어의 손모양과 수형 설명을 보여주고, 사용자가
> 외우고 싶은 단어를 '우리 단어장'에 담아 연습 문제로 복습합니다. 한국수어 **문장 번역기가
> 아닙니다.**
>
> 네이버 로그인은 **단어장을 기기 밖에 저장해 기기를 바꿔도 이어서 쓰게 하는 용도로만**
> 씁니다. 받는 정보는 **네이버가 주는 회원 고유번호(id) 하나뿐**이며, 이름·이메일·전화번호·
> 생년월일·별명·프로필 사진·성별은 **요청하지도, 저장하지도 않습니다.** 앱에서 쓰는 별명은
> 사용자가 직접 입력하는 값이고 네이버에서 가져오지 않습니다.
>
> **회원가입은 로그인과 분리된 별도 화면입니다.** 처음 오신 분은 가입 화면에서
> ① 이용약관 동의(필수 체크) ② 만 14세 이상 진술(필수 체크) 두 가지를 확인하고,
> 개인정보처리방침은 같은 화면에서 **고지**합니다. 개인정보 처리의 근거가 동의가 아니라
> 「개인정보 보호법」 제15조 제1항 제4호(계약의 이행)이므로 **개인정보 수집·이용 동의
> 체크박스를 두지 않습니다.** 계정이 없는 분이 로그인을 누르면 계정을 만들지 않고
> 가입 화면으로 안내합니다.
>
> **만 14세 미만은 가입 대상이 아닙니다.** 법정대리인 동의 절차를 제공하지 않기 때문입니다.
> 생년월일·본인확인·아이핀을 요청하지 않으므로 이 확인은 본인확인이 아니라 **이용자의
> 진술**입니다.
>
> 저장 위치는 Cloudflare D1 이고, 저장하는 것은 (회원 고유번호, 저희가 만든 무작위 계정 번호,
> 단어장 단어 목록, 사용자가 입력한 별명, 로그인 세션 토큰의 해시, 친구 관계, 초대 코드,
> 가입 기록 세 줄)뿐입니다. 회원 고유번호는 계정 행 안에만 두고 밖으로 나가지 않습니다.
> 앱의 '마이 → ⚙ 설정 → 계정 → 계정 삭제'에서 사용자가 직접 전부 지울 수 있습니다.
>
> 로그인 없이도 사전 검색과 연습 기능을 그대로 쓸 수 있습니다.

> ⛔ **옛 기록 — 2026-08-17 이전.** 이 문서는 「현재 구현에는 별도의 회원가입 절차가 없고,
> 소셜 로그인 성공 자체가 계정 생성입니다」라고 적고 있었다. **2026-08-18 로컬 구현으로 그
> 문장은 더 이상 맞지 않는다** — 로그인 경로는 계정을 만들지 않고 `signup_required` 를 돌려준다
> (`worker/index.js` · `scripts/test-signup.mjs` F1~F3). 다만 **그 구현은 아직 배포되지 않았다.**
> 배포 전에 위 문단을 제출하면 라이브에 없는 화면을 설명하는 것이 된다.

## 3. 첨부할 스크린샷

거절 사유 1순위가 「스크린샷 누락」이다. **배포 뒤 라이브에서 찍는다** —
로컬 시뮬레이션 화면을 제출하지 않는다.

| # | 무엇 | 지금 찍을 수 있나 |
|---|---|---|
| 1 | 첫 진입 게이트 — 가입하기 / 로그인 / 로그인 없이 둘러보기 | 배포 후 |
| 2 | 가입 화면 — 요약·약관 링크·필수 체크 2개·제공자 버튼 | 배포 후 |
| 3 | 가입 화면의 **만 14세 이상 필수 항목**이 보이게 | 배포 후 |
| 4 | 제공자 선택 화면에 **네이버 버튼**이 보이게 | 배포 후 |
| 5 | 네이버 동의 화면 | **OAuth 활성화 후** |
| 6 | 가입 직후 화면(마이 탭) | OAuth 활성화 후 |
| 7 | 마이 → ⚙ 설정 → 계정 (**계정 삭제** 버튼이 보이게) | OAuth 활성화 후 |
| 8 | 이용약관 전문 (`/policies/`) | 배포 후 |
| 9 | 개인정보처리방침 전문 (`/privacy.html`) — 「무엇을 받나」 부분 | 지금도 가능 |

3·7·9 를 꼭 넣는다. 「만 14세 미만은 안 받는다」·「사용자가 직접 지울 수 있다」·
「받는 것이 고유번호뿐이다」라는 주장을 화면으로 뒷받침하는 자리다.

⚠️ 저장소의 `네이버검수-캡처/` 는 **사용자 파일이다.** 이 작업에서 열지도, 옮기지도, 지우지도
않았다. 새 캡처를 찍으면 **새 경로에 따로** 두고 그때 승인을 받는다.

## 4. 반려될 수 있는 지점과 확인 방법

| 지점 | 왜 걸리나 | 확인 |
|---|---|---|
| 서비스 URL 이 404 | 옛 GitHub Pages 주소가 남아 있으면 | 콘솔 값을 열어 그대로 브라우저에 붙여 본다 |
| Callback 도메인 불일치 | 네이버는 서비스 URL 도메인 안의 콜백만 받는다 | 둘 다 `shhh-app.pages.dev` 인지 |
| 안 쓰는 동의항목이 켜져 있음 | 코드가 `scope` 를 비워 두는데 콘솔이 이름·이메일을 켜 두면 설명과 다르다 | 콘솔의 「제공 정보 활용 동의」 목록이 **0개**인지 |
| 스크린샷 누락 | 가장 흔한 거절 사유 | 위 표의 3·7·9 |
| 방침 URL 이 안 열림 | `privacy.html` 이 배포에 포함돼야 한다 | 배포 후 `curl -I .../privacy.html` |
| 로그인이 안 됨 | 시크릿 미등록 상태 | `/api/ready` 의 `providers` 에 `naver` 가 있는지 |

[?] 네이버가 요구하는 로고 픽셀 규격을 공식 문서에서 확인하지 못했다. 200/512 두 벌을 준비해 뒀다.
[?] 네이버 로그인 버튼 디자인 가이드의 강제 여부도 확인하지 못했다. 현재 버튼은 네이버 초록
(#03C75A)에 흰 글씨다. 공식 이미지를 요구받으면 그때 교체한다.
