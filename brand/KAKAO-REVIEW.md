## 1. 콘솔에 등록할 값

| 자리 | 값 | 코드 근거 |
|---|---|---|
| Redirect URI | `https://shhh-app.pages.dev/api/cb/kakao` | `redirectUri()` — 카카오는 `viaApp` 이 아니다 |
| 동의항목 | **0개.** 회원번호(`id`)만 쓴다 | `P.kakao.scope = ""` · `uid: (j) => j.id` |
| 부르는 API | `POST /oauth/token` · `GET /v2/user/me` | `P.kakao.token` · `P.kakao.me` |
| 개인정보처리방침 | `https://shhh-app.pages.dev/privacy.html` | — |
| 이용약관 | `https://shhh-app.pages.dev/policies/` | — |
| 로고 | `brand/logo-200.png` · `brand/logo-512.png` | — |

공식 문서가 말하는 콘솔 자리(2026-08-18 확인):

- **[카카오 로그인] > [활성화 설정]** 을 **ON** 으로. 꺼져 있으면 `KOE004` 로 실패한다.
- **[앱] > [플랫폼 키] > [REST API 키] > [Redirect URI]** 에 위 주소를 등록. 틀리면 `KOE006`.
- **[카카오 로그인] > [동의항목]** — 우리는 켤 것이 없다.
- **[앱] > [플랫폼 키] > [REST API 키] > [Client Secret]** — **새 REST API 키는 기본이 사용함**이다.

> 출처: <https://developers.kakao.com/docs/ko/kakaologin/prerequisite>

### Client Secret 을 어느 쪽으로 둘지 — 코드와 맞춰야 한다

`worker/index.js` 는 카카오만 `optionalSecret: true` 다. 뜻은 이렇다.

- 콘솔에서 Client Secret 을 **끄면** `KAKAO_SECRET` 없이도 교환된다.
- 콘솔에서 **켜 두고** `KAKAO_SECRET` 을 안 넣으면 **교환이 실패한다.** 서버는 콘솔이 어느
  쪽인지 알 수 없어서 `/api/ready` 도 이 상태를 못 잡는다 — `providers` 에는 `kakao` 가 뜬다.

**그래서 켜고 값을 넣는 쪽을 권한다.** 끄는 쪽은 「검사에 안 걸리는 실패」를 하나 만든다.

## 2. 팀원 밖 사용자가 로그인하려면 — **확인 필요**

공식 문서(위 링크)는 팀원이 아닌 사용자의 로그인에 **비즈 앱 전환 · 비즈니스 정보 심사 ·
추가 기능 신청**을 든다. 다만 그 문장이 **모든 동의항목에 걸리는지, 이름·이메일 같은
추가 동의항목에만 걸리는지**를 공식 자료에서 확정하지 못했다.

우리 앱은 **동의항목이 0개이고 회원번호만 받는다.** 이 조건에서 비즈 앱 전환이 필요한지는
**확인이 필요한 항목이다.** 추측으로 적지 않는다.

| 확인할 것 | 어떻게 |
|---|---|
| 동의항목 0개인 앱도 비즈 앱이어야 팀원 외 로그인이 되나 | Kakao Developers 고객센터 문의 또는 콘솔의 앱 상태 안내 문구 |
| 비즈 앱 전환 자격 | 사업자등록번호 또는 **개인 개발자 비즈 앱**(전화번호 본인인증). 앱 Owner 만 가능 |
| 개인 개발자 비즈 앱의 제약 | 카카오비즈니스 통합 서비스 약관 동의가 필요하다고만 확인됨 |

> 출처: <https://developers.kakao.com/docs/ko/app-setting/app> · <https://developers.kakao.com/docs/ko/business-auth/common>

**이 항목이 확정되기 전에는 「카카오 로그인이 공개 사용자에게 열린다」고 적지 않는다.**

## 4. 반려·실패가 나올 수 있는 지점

| 지점 | 증상 | 확인 |
|---|---|---|
| 카카오 로그인 비활성 | `KOE004` | 콘솔 [카카오 로그인] > [활성화 설정] |
| Redirect URI 불일치 | `KOE006` | 콘솔 값이 `/api/cb/kakao` 까지 정확한지 (앱 주소가 아니다) |
| Client Secret 켜짐 + 값 미등록 | 교환 단계에서 실패, `/api/ready` 는 정상으로 보임 | 콘솔 설정과 시크릿 등록을 **같은 창에서** 맞춘다 |
| 동의항목이 켜져 있음 | 설명과 화면이 다르다 | 콘솔 [동의항목] 이 0개인지 |
| 팀원 외 로그인 불가 | 심사 전 상태 | 위 §2 — **확인 필요** |
