# 뜻풀이 채우기 — 표준국어대사전 오픈 API 가이드

## 왜 필요한가

카드의 「뜻」 줄은 지금 국어원 수어사전의 **「한국어 대응표현」**(내부 스키마의 `aliases`)을 씁니다.
`내키다 → 싶다 · 원하다 · 바라다 · 소원 · 바람 · 욕구 · 염원 · 원` 처럼 낱말 몇 개라 읽기 좋고,
이미 데이터에 들어 있어 받아올 것이 없습니다.

**문제는 커버리지입니다.**

| 대상 | 대응표현 있음 |
|---|---|
| 전체 표제어 12,943 | **2,326 (18%)** |
| 그림 있는 표제어 3,622 | 1,654 (46%) |

`소령`·`커피`·`보다`·`모르다` 처럼 뜻 줄이 아예 안 뜨는 말이 흔합니다. 나머지 82%를 채우려면
**다른 출처**가 필요하고, 그게 표준국어대사전입니다.

⚠️ **없는 뜻을 지어내지 않습니다**(CLAUDE.md ⛔ 1번). 키가 없으면 그냥 뜻 줄이 안 뜹니다 —
앱은 그 상태로도 온전히 돕니다.

---

## 1. 인증키 발급 (5분, 무료)

1. <https://stdict.korean.go.kr/openapi/openApiRegister.do> 접속
2. 국립국어원 통합 계정으로 **로그인** (없으면 회원가입)
3. 신청 양식을 채웁니다:
   | 칸 | 적을 것 |
   |---|---|
   | 활용 목적 | 개인 학습용 웹앱 (한국수어 학습 앱 `shhh!` 의 낱말 뜻 표시) |
   | 서비스 URL | `https://bu202.github.io/shhh-app/` |
   | 서비스 형태 | 웹 |
4. 신청하면 **16진수 32자리** 키가 나옵니다 (예: `A1B2C3...` 형태)

[?] 승인이 즉시인지 심사가 붙는지는 공식 문서에 안 나와 있습니다. 바로 안 나오면 하루쯤 기다려 보세요.
키를 잃어버리면 같은 페이지에서 재발급됩니다.

## 2. 받아오기

키가 나오면 저에게 주시면 제가 돌립니다. 직접 하시려면:

```bash
cd ~/Desktop/shhh!
node scripts/fetch-meanings.mjs <인증키>        # 전체 (약 12,900개, 30분쯤)
node scripts/fetch-meanings.mjs <인증키> 200    # 앞에서 200개만 (맛보기)
node scripts/fetch-meanings.mjs --mock          # 키 없이 매핑 로직만 자가검증
```

> ⚠️ `scripts/fetch-meanings.mjs` 는 **2026-08-08 커밋 `7e1ed61` 에서 지웠습니다**(대응표현으로
> 갈아타면서 죽은 코드가 됐기 때문). 다시 쓰려면 되살립니다:
> ```bash
> git show 6461aa2:scripts/fetch-meanings.mjs > scripts/fetch-meanings.mjs
> ```

- **키는 로컬에서만 쓰입니다.** 결과 `data/ksl-meanings.json` 에는 키가 안 들어가고, 배포되는
  정적 사이트에도 안 올라갑니다(`fetch-ksl.mjs` 와 같은 방식).
- **이어받기가 됩니다.** 12,900번을 부르는 일이라 중간에 끊기는 게 정상이고, 다시 돌리면
  이미 받은 낱말은 건너뜁니다.
- 연속 5회 실패하면 멈춥니다 — 키가 틀렸을 때 12,900번을 헛돌지 않게.

## 3. 붙일 때 정해야 할 것

받아온 뜻풀이는 **문장**입니다(`영관 계급의 하나. 중령의 아래, 대위의 위이다.`). 지금 카드의
뜻 줄은 낱말 나열이라 그대로 넣으면 두 종류가 섞입니다. 붙일 때 이렇게 하겠습니다:

- **대응표현이 있으면 그대로 둔다.** 국어원이 이 수형에 붙여 놓은 말이라 더 정확합니다.
- **없을 때만** 뜻풀이를 쓰고, **첫 문장·90자**로 자릅니다.
- 출처가 다르다는 걸 화면이 밝힐지는 그때 정합니다.

⚠️ **받아오는 건 낱말의 뜻이지 그 수형의 뜻이 아닙니다.** `보다`처럼 한 낱말에 수형이 여럿인
자리에서 어느 뜻이 어느 수형인지 국어사전은 모릅니다. 그래서 첫 뜻만 싣고, 수형의 뜻이라고
단정하지 않습니다.
