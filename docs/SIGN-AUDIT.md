# 앱이 답하는 수어 vs 실제 쓰는 수어 — 일상어 219개 감사

측정일 2026-08-08 · 재는 도구 `node scripts/audit-signs.mjs` · 앱 코드를 그대로 불러 쟀다(함정 25).

---

## 0. 먼저 — 이 문서가 답하는 것과 답하지 않는 것

**앱의 사전은 국립국어원 한국수어사전 그 자체다.** 이미지 사전 3,622 + 텍스트 사전 13,797 을
병합한 12,943 표제어가 전부 국어원 자료다. 그러니 "앱 ↔ 국어원" 이 어긋나는 자리는
*사전이 틀린 곳*이 아니라 **앱이 사전을 잘못 꺼내 쓰는 곳**뿐이다. 이 문서는 그걸 전수로 쟀다.

**"실제 사람들이 쓰는 수어와 같은가"는 이 문서가 답하지 않는다.** 영상 판독은 사람 몫이다
(`CLAUDE.md` ⛔ — Claude 는 손 그림 판독에서 이 프로젝트에서만 두 번 틀렸다). 지금 **영상으로
확인된 것은 219개 중 8개**뿐이고, 이 문서가 만드는 것은 **나머지를 볼 순서**다.

| 재는 축 | 어떻게 | 이 문서의 답 |
|---|---|---|
| 앱이 사전에서 꺼낸 게 사용자가 친 말과 맞나 | 기계 (전수 측정) | ✅ 아래 등급표 |
| 실제 수어가 있는데 지화로 떨어뜨리나 (**밥 유형**) | 기계 (전수 측정) | ✅ D1 · D2 |
| 그 손짓이 실제 농인이 쓰는 손짓인가 | **영상, 사람 눈** | ❌ 8건만 답 있음 |

## 2. ⛔ C — 조각 섞임 (8건, 최우선)

한 낱말이 손짓과 지화로 쪼개진다. 사용자는 **자기가 친 말이 아닌 말**의 손짓을 본다.

| 친 말 | 앱의 답 | 무엇이 문제인가 |
|---|---|---|
| 자동차 | **[자동]** + 지화'차' | `차`는 1글자 가드에 막히고 남은 `자동`만 손짓이 된다. 자동차를 물었는데 '자동'을 배운다 |
| 편의점 | **[간단하다]** + 지화'점' | `편의`가 [간단하다]로 잡힌다. 편의점과 무관 |
| 좋은아침 | 지화'좋은' + **[일출]** | `아침`이 [일출] 별칭으로 잡히고 앞은 통째로 지화 |
| 선생님 | **[교사]** + 지화'님' | 표제어 `선생님`이 사전에 없어 `선생`만 잡힌다 |
| 짜증나 | **[신경질]** + 지화'나' | 어간 `짜증`만 잡히고 활용 꼬리가 지화로 남는다 |
| 안아줘 | **[포옹]** + 지화'줘' | 위와 같은 꼴 |
| 나중에 | **[나중]** + 지화'에' | 조사 `에`가 지화로 나온다 |
| 키크다 | 지화'키' + **[크다]** | `키`가 1글자라 막히고 [크다]만 남는다 |

**공통 원인 둘**: ① 1글자 가드(함정 16)가 `차`·`키` 를 막는다 ② 활용 꼬리·조사가 어미 목록에 없어
지화로 남는다. 고치는 자리는 `matchSentence` 한 곳이지만 **함정 23 이 요구하는 전수 측정을 먼저 해야 한다.**

### 여기 딸린 별건 2개 (조각인데 둘 다 손짓이라 C 에 안 잡혔다)

| 친 말 | 앱의 답 | 문제 |
|---|---|---|
| **오랜만이야** | [오랜만] + **[이야]** | `이야`가 텍스트 사전의 표제어(=`것`)다. **조사를 손짓으로 내놓는다** — 함정 16 이 막으려던 바로 그것인데 2글자라 가드를 통과했다 |
| **재미있다** | **[반갑다]** + [있다] | `재미`(→표제어 반갑다) 와 `있다`로 쪼개져 **카드 두 장**. 실제로는 한 손짓일 가능성이 높다. 같은 말인 `재밌어`는 E(전부 지화)라 **한 말에 답이 셋** |

## 3. ⛔ D1 — 사전에 있는데 못 찾는다 (3건, 코드로 고침)

말끝만 바꾸면 사전에 정확히 있다. **실제 수어가 있는데 없다고 인식하는** 자리다.

| 친 말 | 앱의 답 | 사전에 있는 것 |
|---|---|---|
| 신난다 | 전부 지화 | `신나다` = **[신나다]** |
| 답답해 | 전부 지화 | `답답하다` = **[답답하다]** |
| 심각해 | 전부 지화 | `심각하다` = **[굉장하다]** (별칭 묶음) |

⚠️ `답답해`·`심각해`는 **`해 → 하다` 규칙으로 고치면 안 된다.** 그 규칙은 `미안해`를
[미안] 에서 [죄송하다] 로 **바꿔버린다**(함정 23·27). 규칙은 전부에 영향을 주고 대장은 그 말에만
영향을 준다 → **부품 1개짜리 대장 항목**으로 닫는 게 맞다. `신난다`(`ㄴ다 → 다`)만 규칙 후보이고,
그것도 넣기 전에 15,000 입력 전/후 대조를 먼저 해야 한다.

## 4. D2 — 밥 유형 (5건, 영상 확인 후 대장)

표제어는 없다. 그러나 **그 말을 품은 합성 표제어가 사전에 있다** — 개념이 KSL 에 존재한다는 증거다.
`밥`이 그랬다: 표제어가 없어 지화로 떨어졌지만 영상을 보니 [먹다] 였다.

| 친 말 | 사전이 품고 있는 표제어 | 짐작되는 것 |
|---|---|---|
| 겨울 | **겨울옷**[동복] | 겨울옷 = 겨울 + 옷 이라면 겨울 손짓이 그 안에 있다 |
| 점심 | **오후**[점심 후] | 점심이 오후의 별칭 안에 있다 |
| 게임 | **액션 게임 · 온라인 게임 · 컴퓨터게임** 외 다수 | 게임 손짓이 공통 부품일 가능성 |
| 공원 | **탑골공원** | 위와 같음 |
| 응원 | **행정 응원** | 위와 같음 |

**전부 확인 필요** — 합성 표제어에 들어있다고 그 부품이 독립 손짓이라는 보장은 없다.
`node scripts/verify.mjs <단어>` 로 유튜브 검색 링크를 받아 사람이 본다.

## 5. B1 — 수형이 여럿인데 미확정 (31건)

화면이 "수형이 N개예요 — 어느 것인지 확인 안 됐어요"를 **정직하게 붙이고 있는** 자리다.
⛔ 위반은 아니지만 사용자가 답을 못 받는다.

`쓰다`(7) · `보다`(5) · `그만`(4) · `바람`(4) · `일`(4) · `뛰다`(4) · `먹다`(3) · `시간`(3) ·
`최고`(3) · `영화`(3) · `여자`(3) · `씻다`(3) · `입다`(3) · `약속`(3) · 그 외 2개짜리 17건.

**설명이 실제로 다른지 재봤다.** 3-gram 겹침으로 후보 설명을 대조한 결과 **29건은 진짜 다른 동작**이고,
`오랜만`(0.86)·`잠깐`(0.94) 둘만 **어순만 다른 같은 동작**으로 보인다 — 이 둘은 화면이 괜히
"확인 안 됨"을 붙이고 있는 셈이다.

`쓰다`는 앱이 [이론]을 먼저 집는다. 쓰다(글)·쓰다(사용)·쓰다(맛)이 섞인 자리라 **가장 위험한 한 건**이다.

## 6. B2 — 별칭으로 잡힘 (57건, 대개 정당)

사용자가 친 말과 카드 표제어가 다르다. **대부분 국어원 사전 자신의 별칭 묶음이라 정당하다** —
`천천히`→[지각], `조심해`→[신중], `돈`→[값] 은 카드가 `천천히 (지각)` 으로 밝혀 준다.

다만 **화면에 뜨는 표제어가 낯설어 사용자가 오해할 만한 것**은 따로 봐야 한다:

| 친 말 | 카드에 뜨는 표제어 | 왜 눈에 걸리나 |
|---|---|---|
| 완전 | **무여**(無餘) | 불경 용어. 그림도 없어 수형설명만 뜬다 |
| 거짓말 | **망어**(妄語) | 불교 사전 표제어 |
| 축하해 · 축하 · 파티 | **식**(式) | 셋이 같은 손짓으로 수렴한다 |
| 따뜻하다 | **남쪽** | "두 손바닥으로 배를 스쳐 올린다" — 남/따뜻하다/봄/포근하다 한 묶음 |
| 앉다 | **지위** | 자리(座)에서 온 묶음으로 보인다 |
| 놀랐어 | **경악** | |
| 고생했어 | **고난** | |
| 진짜 · 정말 | **사실** | |
| 빨리 | **곧** | |

전부 **영상 확인 대상**이지 버그가 아니다. 국어원이 한 묶음으로 정리해 둔 것을 앱이 그대로 옮겼다.
