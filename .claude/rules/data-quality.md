# 한국수어 데이터 품질 규칙

- 사전에 없다는 이유로 개념이나 수어가 없다고 단정하지 않는다. 합성, 이형태, 동음이의를 확인한다.
- 표제어 문자열만으로 수형을 고르지 않는다. 수형이 여러 개면 이미지 ID와 설명을 대조하고 사람에게 선택받는다.
- 자동 수집·AI·유사도 점수는 후보를 줄이는 도구다. 최종 검증 상태는 사람이 확인한 근거만 만든다.
- 뜻풀이 출처가 낱말의 뜻만 제공하고 특정 수형의 뜻을 모르면 그 한계를 보존한다.
- 모르는 값을 임계값이나 첫 번째 결과로 메우지 않는다. 비워 두거나 “확인 안 됨”으로 표시한다.
- 사람이 고른 값은 파생 산출물이 아니라 `data/ksl-verified.json` 또는 `data/ksl-pins.json` 같은 원본 대장에 둔다.
- 생성 스크립트를 import할 수 있으면 CLI 진입부를 직접 실행 가드로 감싼다.
- 규칙을 추가하기 전에 실제 입력 전체를 전후 비교한다. 새 정답뿐 아니라 기존 정답이 틀린 수어로 바뀌는지 측정한다.
- 사전·단어장·연습이 같은 판정 함수를 사용하도록 하고, 미검증 수어를 정답 문제로 출제하지 않는다.
- 데이터 개수와 검증률은 문서의 고정 숫자를 믿지 말고 현재 테스트·스크립트로 다시 계산한다.

최종 수어 판정이 필요한 경우 Claude가 독단적으로 기록하지 않고 근거 후보를 이해하기 쉽게 제시해 사용자가 결정하게 한다.
